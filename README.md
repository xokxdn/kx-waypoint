# Custom GPS Waypoint

A FiveM resource that allows you to customize the appearance of your GPS waypoint by changing its color and marker icon.

## Features

- Custom GPS waypoint color
- Custom GPS waypoint marker icon
- Lightweight and optimized
- Easy installation
- Simple customization

## Installation

1. Download the resource.
2. Extract the folder into your server's `resources` directory.
3. Add the following line to your `server.cfg`:
         ensure kx-waypoint

4. Restart your server.


## Customization

Customize your GPS waypoints appearance by modifying the resources config

You can adjust the waypoint color and marker icon to match your servers preferred style.
